# RAG Series

Code for the courses of the Pluralsight path *Retrieval Augmented Generation (RAG) for Developers*: one folder per
course, each a notebook that runs in Google Colab, with nothing to install.

| Course | What the notebook shows | Run it |
|---|---|---|
| [1 · Vector Space Models and Embeddings in RAGs](1.Vector%20Space%20Models%20and%20Embeddings%20in%20RAGs/README.md) | Embeddings, TF-IDF, the king − man + woman analogy, semantic search and ranking, similarity metrics, PCA, storage size | [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/EasyLearnJava/AgenticProgramming/blob/main/projects/RAG/IT%20Knowledge%20Base/RAG%20series/1.Vector%20Space%20Models%20and%20Embeddings%20in%20RAGs/vector_space_models_and_embeddings.ipynb) |

The path has 12 courses; each gets its folder here as its notebook is written. Courses 2 and 3 already have code
elsewhere in this project: [`Basic/`](../Basic) rebuilds course 2's app, and [`Entry/`](../Entry) holds course 3's
three demos.
