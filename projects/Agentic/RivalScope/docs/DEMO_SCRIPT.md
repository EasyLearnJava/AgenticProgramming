# RivalScope demo script

Aim for **4 minutes 30 seconds**. Start the app before recording. Use the Trello demo for a reliable walkthrough, or run Live research with configured keys and a rehearsed company. Keep the API key file and provider dashboards off screen.

| Time | On screen | Narration |
| --- | --- | --- |
| 0:00–0:30 | Research workspace | “RivalScope helps product managers compare three competitors without assembling pricing, features, positioning, and news by hand. I’m using the Trello demo, which runs the workflow on a fixed set of public sources.” |
| 0:30–1:10 | Click **Find competitors**. Open **Discovery sources**. | “In Live mode, Tavily retrieves candidates and Nebius proposes a shortlist. The app pauses so I can check whether these competitors match the market I actually care about.” |
| 1:10–1:55 | Click **Confirm and research**. Open **Research activity** when the briefing loads. | “RivalScope researches each competitor separately. The demo starts with a simulated gap in ClickUp’s pricing evidence. The activity log shows the targeted follow-up that fills it.” |
| 1:55–2:50 | Show the comparison. Open an Asana or monday.com evidence panel. | “Every accepted finding links to a source and shows its supporting excerpt. Pricing keeps the billing terms visible, and news displays the publication date. Any unsupported field is labeled as a gap.” |
| 2:50–3:25 | Click **Approve briefing**, then download Markdown or CSV. | “Approval makes the briefing available for download. The run is checkpointed locally, so I can reopen the workspace URL and resume where I left off.” |
| 3:25–4:10 | Open **Documentation** and show the workflow or setup sections. | “I used Codex to turn the handout into modular Python code, then separated the provider adapters, orchestration, data validation, and UI. The offline run and mocked provider tests helped verify reviews, recovery, and output.” |
| 4:10–4:30 | Return to the report or display its Markdown copy. | “My evaluation target is eight usable briefs out of ten within five minutes. I’d evaluate it next across companies with clear pricing, quote-based pricing, and ambiguous competitors.” |

For a Live recording, select **Live research**, enter a company, and explain that results may differ from the frozen sample. If a provider stalls, demonstrate the available recovery action or switch to the labeled Trello demo. Before submitting, put the project write-up in a Google Doc, upload the project to GitHub, and add the GitHub link and recording to the course submission.
