How to read the scores

Keyword score is Qdrant's BM25 score, based on matching terms, rarity and passage length. Term rarity is measured within the eligible destination and season, including year-round passages. Each retrieval method ranks its qualifying passages independently.

Semantic score is cosine similarity from −1 to 1. “Not returned” means the hosted search did not return that candidate; “Not available” means no score is available for this run. Neither means a measured zero.

Reciprocal Rank Fusion (RRF) combines those ranks: BM25 contributes {{ diagnostics.keyword_weight }} / ({{ diagnostics.rrf_k }} + rank); semantic contributes {{ diagnostics.semantic_weight }} / ({{ diagnostics.rrf_k }} + rank). Without a BM25 match, a semantic score must also reach {{ diagnostics.standalone_semantic_threshold }} before it contributes. RRF score = keyword contribution + semantic contribution. Keyword-only results use the keyword contribution. Scores measure relevance, not correctness or confidence.

Semantic ranking starts at {{ diagnostics.semantic_threshold }}. A chunk qualifies for the answer with a positive keyword score or semantic similarity of at least {{ diagnostics.standalone_semantic_threshold }}. Qualified chunks are ranked by RRF score, with chunk ID breaking ties.

ColBERT reranking compares the full question with each of the top {{ diagnostics.rerank_limit }} qualifying RRF passages using token-level relevance. Higher ColBERT scores rank first; RRF rank breaks ties. These scores are not probabilities or confidence, and cannot be compared with cosine similarity or RRF scores. “Not reranked” means a passage was outside the shortlist or reranking did not complete; it is not a score of zero.

Final rank follows ColBERT when it succeeds, otherwise the original RRF order. Chat takes up to {{ diagnostics.max_passages }} chunks within its character budget. Retrieved chunks below show the actual context in that order.
